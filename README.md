# Integrated College Management Platform

A cloud‑based Academic Management System built as an MCA final‑year project.

## Tech Stack
- **Frontend**: React.js (Vite) + React Router + Tailwind CSS + Recharts
- **Backend**: Node.js + Express.js REST API
- **Cloud**: Firebase (Auth, Firestore, Storage, Hosting)
